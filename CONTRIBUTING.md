# Contributing to the Marketing jobs list

Help marketers find openings across growth, content, and brand work. Please share the employer's own posting when suggesting a role.

## What belongs in this list

Growth, content, product marketing, brand, communications, and marketing operations roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, and the main marketing focus.

[Open the Add a job form](https://github.com/Jobhacki/marketing-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the marketing role title, employer, link, and what happens when you open the posting.

[Open the Report a dead link form](https://github.com/Jobhacki/marketing-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
